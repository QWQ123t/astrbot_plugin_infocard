# astrbot_plugin_infocard

QQ 资料卡片 + 群管工具插件（AstrBot v4+，仅支持 aiocqhttp 平台）。

## 资料卡片指令

| 指令 | 说明 |
|---|---|
| /开盒 @群友 | 展示该群友的资料卡片 |
| /开盒 QQ号 | 展示指定 QQ 号的资料卡片 |
| /开盒 | 展示自己的资料卡片 |

## 群管指令（仅群管理员/Bot管理员可用）

| 指令 | 说明 |
|---|---|
| /禁言 <秒数> @用户 | 禁言指定成员 |
| /解禁 @用户 | 解除指定成员的禁言 |
| /全禁 开\|关（别名：全员禁言） | 开启或关闭全员禁言 |
| /踢人 @用户 | 将成员移出群聊 |
| /管理员 @用户 | 设置/取消管理员（再次执行即取消） |

## 进群审核

在插件配置或使用 /群审核 开 开启。开启后有人申请进群时：

1. Bot 自动艾特全体管理员，展示申请编号、昵称与验证消息
2. 管理员回复处理：同意 <编号> / 拒绝 <编号> / 拉黑 <编号>
3. 拉黑后该用户再次申请将自动拒绝（黑名单可在插件配置中查看）

## 表情包刷屏防护

在插件配置中开启。开启后群成员在统计窗口内连续发送表情包达到上限时：

- Bot 自动禁言该成员并提示（禁言时长可配置，默认 600 秒）
- 触发上限默认 5 个、统计窗口默认 60 秒，均可在配置中调整
- 发送文字消息会重置连续计数；管理员与保护名单成员豁免

## 卡片使用说明

- 卡片默认 10 秒后自动撤回，可在插件配置中调整撤回时间（0 为不撤回）
- 可开启：自动开盒新进群成员、自动开盒主动退群成员
- Bot 与 Bot 管理员默认受保护；可在"信息保护用户"中添加额外受保护账号
