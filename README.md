# astrbot_plugin_infocard

QQ 用户资料卡片展示插件（AstrBot v4+，仅支持 aiocqhttp 平台）。

## 指令

| 指令 | 说明 |
|---|---|
| `/开盒 @群友` | 展示该群友的资料卡片 |
| `/开盒 QQ号` | 展示指定 QQ 号的资料卡片 |
| `/开盒` | 展示自己的资料卡片 |

## 使用说明

- 卡片默认 10 秒后自动撤回，可在插件配置中调整撤回时间（0 为不撤回）
- 在插件配置中可开启：自动开盒新进群成员、自动开盒主动退群成员
- Bot 与 Bot 管理员默认受保护；可在配置的"信息保护用户"中添加额外受保护账号
